# 덕꾼 (dukkun) 

> **캠퍼스 라이프의 든든한 지원군, 대학 캠퍼스 근거리 C2C 심부름 매칭 플랫폼**  
> "누구나 쉽게 의뢰하고, 누구나 덕꾼(수행자)이 될 수 있는 상부상조 시스템"

<br>

## 📢 서비스 소개 (Overview)
수업 직전 프린트를 깜빡했거나 기숙사에 벌레가 나타났을 때처럼, 캠퍼스 생활 중엔 누군가의 도움이 간절한 소소한 순간들이 있습니다. 
**'덕꾼'**은 이런 일상 속 자잘한 불편함들을 같은 학교 학우들끼리 빠르고 안전하게 돕고 해결할 수 있도록 연결해 줍니다. 
단순한 심부름 대행을 넘어, 서로의 틈새 시간을 가치 있게 나누고 소소한 용돈(포인트)도 벌며 상부상조하는 따뜻한 캠퍼스 문화를 만들어갑니다.

<br>

## 🛠 기술 스택 (Tech Stack)
### Frontend
* **HTML5 / CSS3**: 반응형 웹 디자인 및 시맨틱 마크업 구현
* **Vanilla JavaScript (ES6+)**: 모듈(Module) 패턴 기반의 SPA(Single Page Application)급 동적 렌더링 구현

### Backend / Database (BaaS)
* **Firebase Auth**: 이메일/비밀번호 기반 사용자 회원가입 및 인증 상태 관리
* **Firebase Firestore (NoSQL)**: 사용자, 심부름 게시글, 실시간 채팅, 리뷰, 포인트 로그 등 실시간 데이터 동기화 및 트랜잭션 관리

### Design / Assets
* **Font**: Pretendard
* **Icons**: Google Material Symbols Rounded

<br>

## ✨ 주요 기능 (Key Features)

### 1. 🤖 스마트 매칭 & AI 가격 추천 로직
* **맞춤형 가격 산정**: 출발지-도착지 간의 거리(Zone), 카테고리, 특정 키워드(무거운, 긴급, 벌레 등), 예상 소요 시간을 종합적으로 분석하여 합리적인 심부름 가격을 자동 추천합니다.
* **빠른 매칭(긴급) 모드**: 일반 의뢰와 구분되는 '빠른 매칭' 모드를 지원하여 목록 최상단 고정 및 주변 유저들에게 즉시 긴급 알림을 발송합니다.

### 2. 💬 실시간 채팅 및 다목적 전송 시스템
* **Firestore `onSnapshot` 기반 실시간 채팅**: 매칭 성사 시 자동으로 1:1 채팅방이 개설되며 실시간으로 메시지를 주고받습니다.
* **다목적 데이터 전송**: 단순 텍스트뿐만 아니라, **이미지(자동 리사이징/압축)**, **파일(용량 제한 700KB)**, **내 위치(Geolocation API)**, **정산 계좌 정보**, **재촉 알림** 등을 버튼 클릭 한 번으로 손쉽게 전송할 수 있습니다.

### 3. 💳 안전한 양방향 정산 및 포인트 경제
* **트랜잭션(Transaction) 기반 정산**: 의뢰자와 덕꾼(수행자) 쌍방이 모두 '완료'를 눌러야만 최종 정산이 이루어지는 안전한 로직을 구현했습니다. (한쪽 미응답 시 48시간 후 자동 정산)
* **덕꾼 최소 보장 및 리워드**: 현금(계좌이체) 거래와 별개로, 플랫폼 활동에 대한 리워드로 덕꾼에게는 의뢰 금액의 2%(최소 50P 보장), 의뢰자에게는 50P의 포인트가 자동 적립됩니다.
* **커스텀 영수증 UI**: 브라우저 기본 알림창(`alert`)을 100% 제거하고, 덕꾼 서비스만의 감성이 담긴 세련된 모달과 **정산 영수증 팝업**을 제공합니다.

### 4. 🎨 사용자 커스터마이징 (마이페이지 & 상점)
* **맞춤 알림 설정**: 사용자가 선호하는 캠퍼스 내 특정 위치나 시간대를 설정하여 원하는 알림만 수신할 수 있습니다.
* **아바타 꾸미기 및 아이템 샵**: 심부름으로 모은 포인트를 사용해 상점에서 모자, 안경 등 다양한 액세서리를 구매하고 자신의 아바타에 장착할 수 있습니다.

## 🚀 시작하기 (Getting Started)

1. **Clone the repository**

2. **Firebase Setup**
    * `js/firebase.js` 파일에 본인의 Firebase 프로젝트 Config 설정값을 입력합니다.
    * Firestore Database 및 Firebase Authentication(이메일 로그인)을 활성화합니다.

3. **Run Locally**
    * VS Code의 **Live Server** 확장 프로그램을 사용하여 `index.html`을 실행합니다.
